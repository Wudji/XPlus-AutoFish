## XPlus Autofish (NeoForge 26.1)

XPlus Autofish is an update of [MrTroot's Autofish mod](https://www.curseforge.com/minecraft/mc-mods/autofish) to 1.19.4+, with various new features & bugfixs. This branch contains the NeoForge port for Minecraft 26.1.

In short, just cast the fishing rod into the water once, and it will automatically reel in at the correct time and recast after a couple second wait.

### Features

- Auto fishing with configurable delays
- Multi rod support (auto cycle fishing rods)
- Break protection (stop before rod breaks)
- Persistent mode (auto recast on lag)
- Open water detection (treasure loot conditions)
- Sound-based detection for multiplayer

### Installation

1. Install NeoForge 26.1.0.1-beta or later
2. Download the mod jar from releases
3. Place it in your `mods` folder

### Configuration

Edit `config/autofish-client.toml` after first launch.
